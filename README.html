维护者：Claw 🦞 · 最后更新: 2026-05-06

📖 项目总览

本项目专注于构建一个肝脏疾病相关的蛋白-分子-基因知识图谱（KG），将分散的医学数据源（本体、文献、临床数据）整合为统一的知识图谱，并以此为基础建立一个可供 LLM 高效检索和理解的 Wiki 系统。

🎯 定位

💡 LLM Wiki 是持续的知识基础设施，独立于具体项目。 知识图谱初版（第一阶段）已完成存档，后续方向由新计划决定。

核心功能

  1. 知识存档：记录项目过程中的数据、架构、决策
  2. 任务管理：追踪当前工作和进度
  3. LLM 可读：结构化的资料供 AI 高效检索和理解
  4. 持续演进：跟随新项目方向更新内容

🔬 项目背景（初版参考）

第一阶段的起点是 HepatoOntology 原始医学本体数据和之前构建的医学知识图谱数据集。通过数据清洗、实体补充、字段标准化和质量验证，生成了包含 22,860个实体 和 175,328个关系 的统一知识图谱（已存档，不再维护）。
