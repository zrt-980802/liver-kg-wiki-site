12 - ChEMBL Drug-Target Bridge (v6)

📋 ARCHIVED: 此文档是 ETL 工程日志，记录数据处理过程中的技术细节。保留供历史追溯，不再活跃维护。 最后更新: 2026-05-08

概述

v6 版本在 v5 的基础上，将 Drug 实体中已有的 properties 数据转化为显式的图关系边（Drug→target→Protein），建立了完整的药物-靶点桥梁。

关键发现

1. v5 已做了大部分工作

v5 中的 Drug 实体来源是 ChEMBL，已经将 drug_mechanisms 数据转换为 properties 字段（target_chembl_id, target_uniprot, molecule_type 等）。本版本的主要贡献是将 properties 转换为显式的边。

2. 边类型利用了 action_type

Drug → Protein_Target 边的类型直接使用 ChEMBL 的 action_type（INHIBITOR, AGONIST, ANTAGONIST 等），共 33 种不同的作用模式。

3. 14,709 个缺失的 Protein 实体

Drug 的 target_uniprot 字段指向了图谱中不存在的 UniProt ID（v5 的 Protein 实体覆盖不全）。

补充计划（后续数据集成路线图）

Phase 1: 补齐缺失的 Protein 实体（短期）

问题

14,709 个 Drug 有 target_uniprot 但图谱中无对应 Protein 实体。

解决方案

从 UniProt（https://www.uniprot.org/uniprot/）批量获取这些 ID 的蛋白质信息。

  • 预计新增 ~10,000-14,000 Protein 实体
  • 所需数据：蛋白名称、基因名、物种、序列信息（可选）

最终覆盖率

  • Drug target 覆盖率：83.3%（52,886 / 63,475）
  • 仍无靶点数据：16.7%（10,589 个 Drug）
  • 这些药物主要来自 ChEMBL 但无任何机制记录（大多是”Unknown”或赋形剂类）

什么类型药物缺失靶点？

分子类型分布：Small molecule（~9,023）、Unknown（777）、Protein（579）、Antibody（465）等 原因：ChEMBL 中这些条目没有与任何 target 关联的数据。

关键发现

  • “14,709 个缺失 UniProt” 中实际大部分已在图谱中存在为 Protein 实体
  • 真正的缺失是 43 个 Ensembl Gene ID（ENSGxxxxx）
  • 所有 43 个已通过 Protein_Target 实体的 properties 映射到图谱
  • 无需调用 UniProt/Ensembl 外部 API

Phase 2: 为缺少靶点数据的 Drug 补充机制（中期）

问题

11,448 个 Drug（18%）没有任何 target_chembl_id。

补充策略（按优先级）

策略数据源预计可覆盖工作量
A ChEMBL 按 ChEMBL ID 直接查询chembl_mechanisms_fixed.json+~900低（已有数据）
B PubChem BioAssayPubChem PUG REST API+~3,000-5,000中（按 CID 查询）
C 分子对接/相似性推断Tanimoto 相似度 + 已知靶点+~2,000高（计算密集）
D 文献文本挖掘PubMed + LLM 提取+~1,000高（需要 LLM 调用）

详细说明

策略 A - ChEMBL 补充查询

  • 工具：chembl_mechanisms.json（188K 条自动推断记录）
  • 那些 Drug 没有 curated 机制数据可能在 auto-inferred 中有记录
  • 8,576 个 Drug 在两种机制数据中都无记录

策略 B - PubChem BioAssay

  • 工具：PubChem PUG REST API (https://pubchem.ncbi.nlm.nih.gov/rest/pug/assay/)
  • 按 CID 查询，如果 Drug 有 pubchem_cid 但无 target
  • 限流控制：5 请求/秒

策略 C - 相似性推断

  • 使用 MACCS 指纹/Tanimoto 系数
  • 找到已知靶点药物与新药的结构相似性
  • 需要加载 PubChem 化合物结构数据（~17K SMILES 在 ChEMBL）

策略 D - 文献挖掘

  • 对 Top-K 个重要但无靶点的肝病药物做文献检索
  • 用 LLM 摘要提取靶点信息

Phase 3: 拓展药理网络（长期）

目标

建立更丰富的 Drug-Protein-Gene-Disease 四维关联。

数据源

  • DisGeNET：基因-疾病关联
  • OpenTargets：药物-靶点-疾病证据
  • KEGG PATHWAY：通路中的靶点关系

图查询能力提升

Drug --[targets]--> Protein --[associated_with]--> Disease
Drug --[targets]--> Protein --[in_pathway]--> Pathway
Protein --[interacts_with]--> Protein (已从 STITCH 获取)

Phase 4: 数据质量提升

去重与标准化

  • Drug 实体去重（多个 ChEMBL ID 指向同一物质）
  • Protein 实体合并（UniProt ID ↔ ChEMBL Target ID）
  • 关系去重（同一对实体的多种边类型合并）

缺失值填充

  • 为 Protein 实体补上基因符号、名称
  • 为 Drug 实体补上 ATC 代码、化学分类
  • 为 Property_Target 实体补上描述信息
