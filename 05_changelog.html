v2.2.0 — 2026-05-07

Phase 4: 数据清洗与标准化

P0 - Unknown 实体分类

  • 22,719 个 Unknown 被重新分类
    • 14,370 → Literature（文献实体，ID 以 LIT_ 开头）
    • 8,349 → MeshTerm（MeSH 术语，ID 以 MESH_ 开头）
    • 仅 17 个维持 Unknown

P1 - 同名异类型消歧

  • 6,241 组名称冲突（同名的不同数据库实体）
  • 10,729 个实体的 properties 中添加了 conflict_types 标注
  • 注意：这些确实是不同实体，不做合并（如 ADA 同时存在于 Gene、chebi、mondo）

P2 - 关系类型标准化

  • 103,441 条 OBO 风格关系映射为可读名称：
    • RO:0000087 → has_role
    • BFO:0000050 → part_of
    • BFO:0000051 → has_part
    • RO:0018033 → has_component
    • RO:0018034 → has_component_active
    • RO:0018036 → in_taxon
    • RO:0018037 → is_active_in
    • RO:0018038 → is_active_in_taxon
    • RO:0018039 → acted_on_by
    • RO:0018040 → act_upon
  • 7,281 条其他 OBO 前缀（RO_/BFO_/IAO_）自动转换
  • 所有关系的 original_type 保留在 properties 中
  • 标准化后关系类型种类从 363 → ~210

P3 - Protein ↔ Protein_Target 桥接

  • 1,107 个 Protein_Target 匹配到 Protein 实体
  • 新增 1,107 条 is_target_of + 1,107 条 has_protein_target 边
  • 9,030 个 Protein_Target 未匹配（RNA 靶点、复合物靶点，无可对应 Protein）

P4 - Drug ↔ ChEBI 桥接

  • 3,302 个 Drug 匹配到 ChEBI 实体
  • 新增 3,302 条 has_chebi + 3,302 条 is_chebi_for 边
  • 匹配方式：Drug ID (CHEBI:) / Drug name / ChEBI synonym

数据状态

  • v8.0 — 658,247 实体 / 1,583,064 关系 (730.8 MB)
  • 新实体类型：Literature (14,370), MeshTerm (8,349)
  • 新关系类型：is_target_of, has_protein_target, has_chebi, is_chebi_for
  • 关系类型数量大幅精简

📊 网络分析结果

  • 网络规模: 23,395 节点, 71,779 边（清理前缀后）
  • 枢纽发现: Top 5 = HYDROGEN(6,968), OXYGEN(3,421), NAD+(1,950), CO2(1,877), ATP(1,740)
  • 社区发现: 1,363 个社区, 最大社区 5,724 节点（基础代谢核心）
  • 关键洞察: 网络中心多为内源性代谢物而非外源药物, STITCH 化学-化学网络更多反映代谢通路
  • 新文档: 10_stitch_network_analysis.md — 完整分析报告
