项目概览与架构

肝病蛋白分子基因知识图谱项目 — 概述与技术架构
最后更新: 2026-04-27

1. 🎯 项目背景与目标

1.1 为什么做这个项目？

肝病是全球性的重大健康问题。虽然有大量的医学数据（本体、文献、临床记录）可用，但这些数据分散在不同的格式和系统中。但更深层的问题是：知识图谱的构建者（按实体-关系-属性的结构化方式组织数据）与使用者（按临床路径/科研假设的思维模式工作）之间存在认知鸿沟。

本项目旨在弥合这种鸿沟，而非单纯打通数据孤岛。

  1. 弥合构建者-使用者鸿沟：通过临床场景层将用户的思维路径映射到图谱拓扑结构
  2. 跨模态语义对齐：将异构数据源在语义层面统一，实现跨源知识的可互换性
  3. 可解释的证据链推理：将图谱查询结果转化为用户可理解的推理过程和决策依据

详细动机分析：请参见 项目动机 - 临床发现与科研发现 项目定位分析：请参见 项目定位与价值分析 Phase 3-4 核心功能：请参见 Phase 3-4 核心功能说明

1.2 核心问题

问题描述解决方案
数据异构本体(OBO)、文献(XML)、临床数据(CSV)格式不统一标准化为统一 JSON schema
知识融合多源数据中实体冲突、关系重叠实体对齐 + 关系合并 + 冲突解决
LLM 可读性图谱数据量大，LLM 上下文有限分层结构 + 质量优先的索引
持续更新医学知识在快速演进自动化流程 + 定期更新机制

2.2 核心方法框架：三大贡献

项目当前聚焦三大核心方法贡献，而非简单复刻 AliCoCo：

方法解决的问题状态
① 临床场景层用户思维路径 vs 图谱拓扑结构的鸿沟✅ 设计完成
② 跨模态语义对齐多源数据语义颗粒度差异的对齐与融合🚧 待实现
③ 证据链推理（三层模板架构）图谱结果 vs 用户决策依据之间的可解释性鸿沟📋 方案设计

这并不是简单的 AliCoCo 复用，而是将”认知鸿沟的弥合”作为独立研究命题升维后，在生物医学领域的原创解决方案。
